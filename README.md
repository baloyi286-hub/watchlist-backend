# WatchCue Backend

Spring Boot REST API for WatchCue. Vercel deployment uses `Dockerfile.vercel` and listens on `$PORT`.

Required production database variables: `SPRING_DATASOURCE_URL`, `SPRING_DATASOURCE_USERNAME`, `SPRING_DATASOURCE_PASSWORD`. Optional: `YOUTUBE_API_KEY`, `TV_NOTIFICATION_URL`, `TV_API_KEY`.
